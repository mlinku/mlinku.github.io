# 构建旅行手册

网页源码统一维护在 `kansai-src`。`build-site.mjs` 同时负责两种交付，行程选择逻辑、文案和样式不再维护两套。

```powershell
node kansai-src/build.mjs
node kansai-src/verify-redesign.mjs
node kansai-src/verify-polish.mjs
```

- 博客版输出 `kansai/index.html`：数据与脚本为独立文件，图片使用缩略图、响应式尺寸和延迟加载，放大时读取原图。资源名包含内容哈希。每次构建会删除 `kansai/assets` 中本次未引用的旧哈希文件。
- 离线版通过本地 `可视化网页/build.mjs` 调用同一构建器：照片、数据和样式全部嵌入 HTML，双击打开不需要服务器。
- 博客缩略图构建使用 Python + Pillow；可用 `KANSAI_PYTHON` 指定 Python 路径。浏览器和读者不需要这些依赖。
- 离线目录中的源码文件由离线构建同步，仅作镜像。请在 `kansai-src` 修改后重新构建。

`dayPresentation()` 统一生成当前选择下的日标题、摘要和封面；`mealRows()` 统一决定餐厅首选、预算、地图和备选顺序。请勿在各视图另写替换条件。

每日以行程为主，`routeOverview()` 在顶部生成默认收起的地点索引，沿用 `timedRoute()` 的顺序、返程用途和当前选择；完整换乘与执行说明保留在活动中。有巡礼的日期才显示行程／巡礼切换。旧 `route`、`gallery` 地址以及 `timeline/route` 地址均进入主行程并展开路线索引。

样式只有一份 `site.css`：一张印好的行程表放在桌面上——白纸黑字、细线分隔，几乎不用卡片框；藏青只用于可点击内容，时间用加粗等宽数字，红黄绿只标状态。日间为基础，夜间只在顶部变量里换色。

版面：正文是一张居中的纸面（`--sheet` 900px），左侧保留侧栏；每项活动默认收起为一行：开始时间、主项缩略图、标题（主项粗体，交通／休息等次项浅色）、⚠（有注意事项）、导航、完成。点标题展开说明、餐厅、换乘、巡礼、可调整与更多；同一时间只展开一项。旅行当天自动展开当前活动，工具栏显示「下一站」，点它跳转并展开。电脑与手机同一版本。连续两步以上的次项（交通、步行、休息、到达）合并为一行「移动 · N 步」，显示起点 → 终点和终点导航；勾选它会完成其中每一步，展开后可逐步勾选（`moveRuns`、`moveCard`）。跨时段的一段移动整体放在开始的时段。

日夜模式：默认跟随系统，侧栏按钮切换。与博客共用 `localStorage` 的 `user-color-scheme` 和 `<html data-user-color-scheme>`（博客的 `js/ui/mode.js`），在任一处切换，另一处同步。页面头部的 `#color-mode` 小脚本在渲染前应用选择，避免闪烁。

阅读顺序：总览先给出发倒计时或「今天」入口、三步用法和术语说明；每日页顶部依次是今日要点、情况有变时、住宿，下面的活动卡统一为「时间｜内容」，多站交通显示为按顺序排列的地图链；准备页把票务状态放在最前，待办分为「出发前完成」和按日期的「旅途中再确认」（`TODO_WHEN`）。

活动卡只显示一句说明：说明较长的活动在 `daily.js` 的 `EVENT_BRIEF` 写短句（空字符串表示「怎么走」已说明、卡片不再重复），原文保留在「更多 → 完整说明」，规划数据不改。三站以上的交通默认只显示目的地，沿途车站折叠；已完成的活动收成一行，点标题展开。出发后总览的用法说明折叠为一行。

「今天」与「现在」按日本时间计算，只用于提示阅读位置，从不自动标记完成。预览其他时刻可在地址加 `?now=2026-12-02T14:40`。

在本地旅行目录构建时，两版都以旅行目录的三份规划文件为准；博客构建自动同步到 `kansai-src/data`。独立克隆仓库时使用已提交的数据副本。文档中的交通、票券和地点来源应保持完整。

本地记录沿用 `kansai-autumn-notebook-v1` 存储键，`schemaVersion: 3` 的活动值为 `pending`、`done`，旧 `skipped` 按未完成迁移；拍摄仍沿用 `日期:shot:点位ID` 的布尔值。首次升级在任何迁移写入前，将旧存储原文保存在 `kansai-autumn-notebook-v1-before-activity-v3`（键已占用且内容不同则追加时间戳）。需要恢复时可从浏览器开发工具导出该值，再写回原存储键并刷新；先导出当前记录，恢复会替换当前进度。备份失败时不会覆盖旧存储。各浏览器和网页／文件来源分别保存。

标题字体：`assets/fonts/kansai-serif-700.woff` 与 `-900.woff` 是 Noto Serif SC（SIL OFL 1.1，见同目录 `OFL.txt`）按 `serif-chars.txt` 精简出的两个字重，各约 45KB。博客版作为哈希资源发布，离线版嵌入样式。标题出现新汉字时，把字加进 `serif-chars.txt`，运行 `python kansai-src/subset-font.py`（需要 fontTools，默认读取 Windows 11 自带的 `NotoSerifSC-VF.ttf`）。缺字会逐字退回系统宋体。

巡礼页为单栏：点位目录在顶部两栏排列，手机用下拉跳转。
