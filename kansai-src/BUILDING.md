# 构建旅行手册

源码统一维护在 `kansai-src`，`build-site.mjs` 同时负责博客版与离线单文件两种交付，行程规则、文案和样式只有一套。

```powershell
node kansai-src/build.mjs              # 博客版 → kansai/index.html，并补齐博客入口
node 可视化网页/build.mjs               # 离线单文件 → 旅行目录 可视化网页/index.html（在旅行目录里运行）
node kansai-src/trip/verify.mjs        # 界面与文案规则
node kansai-src/verify-polish.mjs      # 复制失败的回退
node kansai-src/verify-final-plan.mjs  # 2026-10-19最终计划；机酒与未改日期不变
node kansai-src/verify-delivery.mjs [离线文件路径]   # 构建产物：数据、资源与内嵌情况
```

## 文件

- 领域：`details.js`（每日资料）、`app.js`（存储与迁移、可选安排 `choice`／`effectiveEvents`、复制与提示）、`day-flow.js`（时段分组）、`execution.js`（导航站点、现场注意事项）。
- 界面：`trip/model.js` 把规划数据解析成界面要显示的对象，`trip/ui.js` 只负责排版与交互，`trip/trip.css` 是唯一样式表，`trip/assets/` 放界面图片。
- 构建：`build-site.mjs` 的 `SCRIPT_FILES`／`STYLE_FILES` 决定打包顺序（领域在前）。博客版的数据与脚本为独立文件，图片用 640px 缩略图并延迟加载，放大时读取原图，资源名含内容哈希，每次构建删除 `kansai/assets` 中未引用的旧文件；离线版把照片、数据、字体和样式全部嵌入 HTML，双击即可打开。启动时 `app.js` 把内嵌照片的 data URI 一次性换成短的 `blob:` 地址，渲染时不再携带图片数据。博客缩略图需要 Python + Pillow（`KANSAI_PYTHON` 可指定路径），读者不需要。离线目录里的源码文件是构建同步的镜像，只读。
- 在旅行目录构建时以旅行目录的三份规划文件为准，博客构建会同步到 `kansai-src/data`；独立克隆仓库时使用已提交的数据副本。

## 界面

- 底部四个标签：**现在**（出发前为「总览」，结束后为「回顾」）、**行程**、**巡礼**、**准备**。
- **现在**：正在进行或下一项活动，顶部是目的地照片，带「导航」和「完成」大按钮；完成后自动换到下一项，可撤销。下面依次是接下来 3 项、当天关键时间（`HARD_STOPS`，带倒计时，1 小时内标红）、今晚住处与复制地址、情况有变时。每分钟和切回页面时刷新。
- **行程**：顶部日期条；每天的页头是一张车票（封面照片、带打孔缺口的虚线、离店／返店／强度票根）；活动按时段排成一条电车线，主项是照片或图标站点，次项是小点，一步一行，不合并。右侧圆圈直接勾选；点一行从底部弹出详情，导航与完成固定在底部，手机返回键关闭。
- **巡礼**：按天列出点位，作品画面与实景并排，点图全屏并可来回切换对照；「已拍」单独记录。
- **准备**：票务、待办（出发前完成／按日期的旅途中再确认，`TODO_WHEN`）、航班、酒店与参考资料，最后是返回博客。
- 旧地址仍能定位：`#day/日期/timeline/活动` 打开该活动详情，`…/pilgrimage/点位` 进入巡礼，`…/timeline/route`（已取消的路线页）打开当天行程。最终计划换日的活动（原12/5奈良、日本桥与戎桥，`MOVED_LINKS`）打开新日期的同一活动并提示；已取消的活动（USJ、大阪城等）只打开当天行程并说明。巡礼点链接按点位所在日期打开。
- 巡礼的参考点（`reference`，如通天阁）收在「参考资料」里，不在当天行程、不计进度、不能标记已拍。
- 「今天」与「现在」按日本时间计算，只提示阅读位置，从不自动标记完成。预览其他时刻可在地址加 `?now=2026-12-02T14:40`。

## 文案

- 取舍集中在 `trip/model.js`：`eventModel()` 把一项活动解析成一个对象（短句、注意事项、交通、餐厅、照片、完整说明……）。
- 说明较长的活动在 `EVENT_BRIEF` 写一行短句（空字符串表示「怎么走」已说明）。原文中卡片上还没说过的句子（逐句比较，不计短句、交通、地点说明、详情与「情况有变时」已有的）收进默认收起的「完整说明」。
- `FALLBACK_SHORT` 精简「情况有变时」，短句必须保留状态词（待确认、未购买、尚未订位）、安全限制与截止时间；`TRANSPORT_SHORT` 把机场交通说明压到只剩时间与易错点。
- `DROP_COPY`／`DROP_SENTENCES` 逐句去掉老手不需要的提醒（机场流程、「以现场为准」「按现场指引」「请询问店员」、核实记录）和只是复述短句的规划句；`DROP_DETAILS` 去掉与「怎么走」重复的机场手续面板；`cleanText` 去掉时间前的「参考」与「临行复核」类从句（复核放在准备页的待办里）。
- 易错提醒（如「不要误进JR闸机」）加粗标出，线路名显示为站牌式标签。
- 规划数据不改。`trip/verify.mjs` 检查：每条精简与删除规则仍能在原文找到；关键时间的每个时刻都出现在规划数据自己的文字里；每项活动在所有可选组合下都能打开详情；交通容器保留 `aria-label="交通说明"`；原文每句仍可见；截止时间与易错提醒仍在页面上；旧地址可定位；旧进度按最终计划迁移；规划数据未被改动。

## 外观

- 「旅のしおり」，配色取自《千恋＊万花》与丛雨：偏黄绿的米色和纸；可点击与当前位置用绿色——大面积填充为叶绿 `--accent-fill`／淡绿 `--accent-pale`（上面是深绿字），文字与图标为 `--accent`；发带紫与金只作装饰（金色不用于文字）；朱只用于印章。页面顶部有渐隐的菱形格纹，标题前是五瓣小花，宋体标题。红色截止一律配图标或文字。
- 户外取值：正文与辅助文字在各底色上不低于 4.5:1，控件轮廓不低于 3:1，点击区域不小于 44px。
- 夜间为「夜の穂織」墨绿色，只换 `trip.css` 顶部变量；与博客共用 `localStorage` 的 `user-color-scheme` 与 `<html data-user-color-scheme>`（博客的 `js/ui/mode.js`），页面头部的小脚本在渲染前应用，避免闪烁。状态栏颜色随日夜（`buildSite` 的 `themeColor`）。
- 完成标记是丛雨：勾选后圆圈里出现她闭眼微笑的头像（`trip/assets/murasame-done.jpg`，原图按脸部 440px 方形裁切、缩到 192px），弹入一次后静止；当天全部完成时「现在」页显示整张插画（`murasame-banner.jpg`）。巡礼「已拍」与 8 天列表的整天完成用「済」印，每天一枚「N日目」日期印。图片来自游戏《千恋＊万花》；喜多出自《孤独摇滚！》。
- 手绘线稿（`trip/doodles.js`）：单色笔触跟随 `currentColor`，下面一层淡彩晕染，再叠一层错位半像素的淡描线和共用的抖动滤镜（`#doodle-rough`）做出钢笔速写感。每天一张城市小图（`DAY_DOODLE`：飞机、抹茶碗、红叶、鸟居、鹿、海边天守、大桥、行李箱），放在「现在」页标题旁与车票照片右上角的贴纸里；两张宽场景（`SCENES`：出发的列车、归途的飞机与京都塔）放在出发前倒计时与行程结束的回顾页。宽场景线宽不随缩放变化。
- 喜多（《孤独摇滚！》）的小人（`trip/assets/kita-*.webp`，从白底立绘抠出、边缘去白晕）每个标签各有姿势，都放在卡片里、不伸出卡片：总览倒计时卡上跳起来欢呼、「接下来」标题旁奔跑、回顾页欢呼；行程「关键时间」标题行里趴着看（当天全部完成后咧嘴笑）；巡礼页标题旁侧坐、旁边一枚相机线稿（当天全部拍完换成闪光）；准备「待办」标题行里坐着笑，「准备」标题旁是清单线稿，「票务」卡角有一张车票线稿。行程行、详情与交通说明里不放任何手绘或人物。各标签的卡片标题前标记也不同：现在✿、行程站点圈、巡礼✦、准备✓。
- 只有主活动（参观、吃饭、购物、巡礼步行、航班）有完成章，进度只计主活动；交通、步行、休息是连接行：不盖章、不显示钟点，只写时长，后面的活动勾选后自动变淡。固定时刻（航班、候选列车、订位目标，`fixedTime`）粗体，其余规划时刻用较浅字重。勾选与已拍不弹提示，再点一次即可取消。时间段写成「19:00 – 19:30」。
- 行程页不再单列「路线」：顺序就是行程行本身，每段交通详情里的「沿途 N 站」逐站带地图。
- 行程行的时间、圆点、标题首行与勾选圈都以 20px 处为中心（标题固定行高），竖线位置与时间栏共用 `--t` 宽度。
- 样式表用 `url(@font/<文件>)` 引用字体、`url(@src/<kansai-src 内路径>)` 引用图片，构建时内嵌（离线）或发布为哈希资源（博客）。
- 圆角四级 `--r-xl`／`--r`／`--r-md`／`--r-sm`（标签等小件 4—8px），缓动 `--ease-out`、`--ease-spring`。详情从屏幕底边滑上、关闭时滑回，放大图淡入淡出；切换标签或日期时内容轻微上浮淡入，日期条从原位置滑到所选日期；勾选等原地刷新不触发入场动画，并保留展开的折叠。系统开启「减少动态效果」时全部关闭。
- 标题字体 `assets/fonts/trip-serif-700.woff`／`-900.woff` 是 Noto Serif SC（SIL OFL 1.1，见 `OFL.txt`）按界面实际用到的字精简（约 650 字，各约 146KB）。活动名、地名或标题出现新字时运行 `node kansai-src/trip/fonts.mjs`（需要 fontTools 与 Windows 自带的 `NotoSerifSC-VF.ttf`），它重写 `trip-serif-chars.txt` 并调用 `subset-font.py`。

## 本地记录
